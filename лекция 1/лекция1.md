## Команда print()
Команда `print(x, y, z)` – это функция которая печатает текст в консоль.
Разберём запись `print(x, y, z)`:
1. print – имя функции
2. x, y, z – аргументы фукнции
3. () – скобки, которые необходимо указывать, чтобы вызвать функцию

### Примечания:
1. Можно передавать сколько угодно аргументов
2. Если передаём несколько аргументов, их нужно указывать через запятую

#### пример 1
вывод одного аргумента – строки 'Привет!'

```python
print('Привет!')
```

#### пример 2
вывод двух аргументов

```python
print('Привет!', 'Лиза')
```

#### пример 3
Так же можно печатать числа, в примере печатаем 3 числа

```python
print(1, 2, 3)
```

## Переменная
Переменная – это способ сохранить в программе какое-то значение. Иначе говоря, это коробочка, в котороую можно положить значение.

## Команда input()
Команда `input()` – это функция, которая ожидает пока пользователь сам введёт какие данные в консоль

## Операции сравнения

### Числа

```python
1 < 2 # меньше
2 > 1 # больше
2 == 2 # равенство
2 != 1 # неравество
```

### Строки

```python
'abc' == 'abc' # равенство, True
'abc' != 'qwe' # неравество, True
'abc' != 'abcc' # неравество, True
'abc' == 'abbc' # равество, False
```

## Условный оператор

```python
if (условие верно):
    что-то делаем
else:
    делаем что-то другое
```

#### Пример 1

```python
if (1 < 2):
    print('1 меньше чем 2')
else:
    print('1 больше чем 2')
```

#### Пример 2

```python
if ('abc' == 'abc'):
    print('abc тоже самое что и abc')
else:
    print('abc не тоже самое что и abc')
```
